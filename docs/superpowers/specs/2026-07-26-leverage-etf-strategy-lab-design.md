# 槓桿 ETF 策略實驗室設計規格

日期：2026-07-26  
狀態：已批准進入實作  
專案：`leverage-etf-strategy-lab`

## 1. 產品目標

建立一個公開、可重現、可擴充的 ETF 回測網站。第一版完整支援：

- 台股組：0050／00631L。
- 美股代理組：00646／00647L。
- 各交易對獨立策略回測。
- 多交易對策略合併與跨組再平衡。
- Yahoo Finance 歷史資料、月度補抓與本機快取。
- 專業圖表、績效與風險分析、方案比較。
- 本機最佳化與 ChatGPT 分析包，不依賴 API 金鑰。
- GitHub Public Repository、PR／Commit／Tag／CI 維護。
- Tailscale Funnel 公開 HTTPS 網址。

本產品提供研究與教育用途，不產生個人化投資建議，也不保證未來績效。

## 2. 已確認決策

### 2.1 資料

- 正式資料源為 Yahoo Finance chart API。
- 儲存開盤、最高、最低、收盤、還原收盤、成交量、股息與拆分事件。
- 首次建立完整快取；後續啟動時只在資料未涵蓋到「上個月月底」時補抓。
- 例如 8 月 1 日啟動時，必要截止日為 7 月 31 日；若當日非交易日，接受最近交易日。
- 顯示資料來源、最後交易日、必要截止日、缺口、異常值及更新時間。
- 支援 CSV 匯入，並保留日後更換資料供應器的介面。

### 2.2 回測價格與股息

三種模式：

1. 總報酬：使用還原價格，股息視為立即再投入。
2. 純價格：使用未還原價格，不計股息。
3. 股息現金：使用未還原價格，股息先進入「待投入股息現金」。

股息現金仍計入投資組合資產，但不計入市場曝險。使用者可按日期、標的與比例設定加碼；每次股息與再投入都產生現金流和交易紀錄。

### 2.3 成交與成本

- 訊號於交易日收盤後產生，於下一交易日開盤成交。
- 研究模式允許小數單位，避免整股與零股造成比例誤差。
- 交易成本預設為零。
- 啟用成本後載入可更新的「國泰證券」範本，並允許修改買賣手續費、折扣、最低手續費、賣出稅及滑價。
- 成本範本標示查核日期，避免將可能變動的費率寫死成永久事實。

### 2.4 曝險與持倉

- 每個交易對只持有原型 ETF 與其槓桿 ETF。
- 兩檔目標權重合計 100%，不主動配置現金。
- 待投入股息現金為唯一例外。
- 原型 ETF 以 1 倍、槓桿 ETF 以 2 倍近似時，組合名目曝險約為：

```text
名目曝險 = 原型 ETF 權重 × 1 + 槓桿 ETF 權重 × 2
         = 100% + 槓桿 ETF 權重
```

- 介面同時顯示目標權重、實際漂移權重與估計名目曝險。

## 3. 策略規則引擎

### 3.1 基準

- 0050／00631L 使用 0050 判斷歷史新高、回撤與反彈。
- 00646／00647L 使用 00646 判斷歷史新高、回撤與反彈。
- 歷史高點只使用當日以前已知的收盤價，不使用未來資料。

### 3.2 市場階段

規則引擎保存狀態並區分：

- `AT_HIGH`：創新高或在新高容許範圍內。
- `DECLINE`：自前高下跌，尚未確認進入反彈。
- `RECOVERY`：自目前谷底反彈。

同樣距前高 20% 時，`DECLINE` 使用加碼階梯，`RECOVERY` 使用減倉階梯。狀態與轉換原因寫入操作紀錄。

### 3.3 可設定規則

- 基礎持有比例。
- 創新高時的目標比例，例如 30% 0050／70% 00631L。
- 回撤階梯，例如回撤 10%、20%、30% 時逐步提高槓桿 ETF 至 100%。
- 反彈階梯：按「自谷底反彈」或「距前高」逐步降低槓桿 ETF。
- 接近前高指定距離時恢復基礎比例。
- 規則優先序與啟用／停用。
- 再平衡方式：
  - 僅規則事件觸發。
  - 每日、每週、每月、每季、每年。
  - 權重偏離目標達指定百分點。
  - 完全不再平衡。

## 4. 單組回測

- 任一共同交易日可作為開始日。
- 使用者設定單次投入金額與結束日。
- 兩交易對分開執行，不混用訊號。
- 產生每日資產、持倉、權重、曝險、現金、回撤與階段序列。
- 產生所有訊號、下單、成交、股息、再投入、再平衡及成本紀錄。
- 同時比較：
  - 使用者策略。
  - 100% 原型 ETF 買入持有。
  - 100% 槓桿 ETF 買入持有。

## 5. 多組策略組合

多組策略組合是獨立於單組回測之上的第二層：

- 每個交易對可選擇不同的已儲存策略版本。
- 每個子策略先獨立產生每日 NAV，再由組合層配置資金。
- 初版支援任意數量交易對，不將程式寫死為兩組。
- 可設定例如台股策略 40%、美股策略 60%。
- 跨組再平衡支援：
  - 不再平衡。
  - 每月、每季、每年。
  - 任一子策略權重偏離目標達指定百分點。
  - 週期與偏離門檻的聯合條件。
- 組合層保留子策略內部交易與跨組資金移轉的分離紀錄。
- 組合層績效可與每個子策略、各原型 ETF 及各槓桿 ETF 比較。

## 6. 績效與風險分析

每個單組策略與多組策略組合都計算：

- 期末資產、總報酬、CAGR。
- 年化波動率、下行波動率、Sharpe、Sortino。
- 最大回撤、最大回撤起訖、谷底、恢復日與持續天數。
- Calmar、Ulcer Index、VaR、CVaR。
- 最佳／最差日、月、年。
- 勝率、報酬分布、滾動 1／3／5 年報酬。
- 平均與最大名目曝險。
- 換手率、交易次數、成本總額與成本侵蝕。
- 待投入股息現金的平均與最大占比。

## 7. 最佳化與穩健性

不需要 API 金鑰即可使用：

- 參數網格窮舉。
- 可重現的隨機搜尋。
- 多目標 Pareto 前緣。
- 最高 CAGR、最高 Sharpe、最高 Calmar、最低回撤及平衡分數分別排名。
- 樣本內／樣本外切分。
- Walk-forward 滾動驗證。
- 參數穩健度熱圖。
- Bootstrap／Monte Carlo 路徑壓力測試。
- 交易成本敏感度分析。

每次最佳化保存搜尋空間、資料指紋、隨機種子、評分方式和候選結果。

## 8. AI 分析包

因 ChatGPT 訂閱不包含 API 額度，第一版不要求 API 金鑰：

- 一鍵建立 JSON 分析包。
- 一鍵建立精簡 CSV：每日 NAV、交易紀錄、回撤區間及年度報酬。
- 一鍵複製 ChatGPT 專用提示詞。
- 提示詞要求 AI 區分已觀察事實、推論與風險，不以樣本內最優值作未來保證。
- 未來可透過同一 `AnalysisProvider` 介面接入 OpenAI 或其他模型。

## 10. 儲存與重現

- 第一版使用 IndexedDB。
- 支援策略、回測快照、最佳化結果與多組組合。
- 支援命名、標籤、複製、封存、比較、JSON 匯入匯出。
- 每個結果保存：
  - 資料版本與雜湊。
  - 策略版本。
  - 引擎版本。
  - 成本與股息設定。
  - 執行時間與隨機種子。
  - 結果指紋。

## 11. 技術架構

- Vite + TypeScript。
- UI 使用原生 HTML／CSS 與小型元件函式，避免不必要的大型框架。
- TradingView Lightweight Charts 負責金融圖表。
- Web Worker 執行最佳化，避免阻塞 UI。
- Vitest 測試純函數回測、規則、指標、資料及組合層。
- Playwright CLI 執行桌機與手機核心流程、截圖與視覺 QA。
- Node 資料服務負責 Yahoo 補抓、快取及本機靜態服務。

主要邊界：

```text
UI
 ├─ StrategyService ─ BacktestEngine ─ Metrics
 ├─ PortfolioService ─ MultiPortfolioEngine
 ├─ OptimizationService ─ Worker
 ├─ ChartAdapter ─ Lightweight Charts
 ├─ StrategyRepository ─ IndexedDB
 └─ DataClient ─ Local Data API ─ YahooProvider ─ File Cache
```

## 13. 錯誤處理

- 資料抓取失敗時使用最後成功快取並顯示過期程度。
- 缺少某標的共同交易日時不進行猜測，顯示被排除日期數量。
- 非法權重、重複門檻、無下一交易日成交、價格為零或缺失時拒絕執行並指出欄位。
- 最佳化可取消、顯示進度，頁面重整後不宣稱未完成結果成功。
- 匯入檔案先驗證 schema 與版本；不執行檔案中的程式碼。

## 14. 驗收標準

1. 兩交易對能以任一共同交易日起始，使用單次投入與小數單位完成回測。
2. 三種股息模式都有測試；股息現金可延後投入並留下紀錄。
3. 回撤加碼與反彈減倉在相同距前高下依階段產生不同目標。
4. 所有訊號於下一交易日開盤成交。
5. 權重合計 100%，除待投入股息外不留現金。
6. 能儲存兩組不同策略，再建立 40／60 多組組合並按年度或偏離門檻再平衡。
7. 圖表能比較策略與兩個原型 ETF／槓桿 ETF，顯示操作標記和回撤區。
8. 能儲存、比較、匯出與重新匯入方案。
9. 最佳化提供多目標排名、Pareto 結果和可重現設定。
10. 啟動時檢查上個月月底，資料足夠時不重抓，不足時只補抓。
11. `npm run lint`、`npm run typecheck`、`npm test`、`npm run build` 全部成功。
12. 412 × 915 與桌機 1440 × 900 的核心流程可用。
13. Public Repository 可透過 PR／Commit 維護，並附 Tailscale Funnel 操作文件。

## 15. 第一版範圍界線

- 不含券商自動下單。
- 不含即時盤中訊號。
- 不含登入與雲端同步，但保留接口。
- 不含 API 型 AI 對話，但提供本機最佳化與 ChatGPT 分析包。
- 不把回測結果描述為投資建議或未來保證。
